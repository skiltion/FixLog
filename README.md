# FixLog

## 프로젝트 이름

**FixLog**

## 프로젝트 소개

FixLog는 개발 중 발생한 오류와 실제 해결 방법을 기록하고 공유할 수 있는 공개 오류 해결 웹서비스입니다.

사용자는 로그인이나 회원가입 없이 다른 사람이 등록한 오류 해결 기록을 검색하고 확인할 수 있으며, 자신이 직접 해결한 오류도 등록할 수 있습니다. 기존 해결 기록이 부족한 경우에는 Google Gemini API를 이용해 오류의 원인, 해결 순서, 주의사항 등을 AI로 분석할 수 있습니다.

## 주요 기능

- 개발 오류 제목, 오류 메시지, 해결 방법, 태그 검색
- 기술별 오류 기록 필터링
- 최신순 / 도움순 정렬
- 실제 해결한 오류와 해결 방법 공개 등록
- 오류 상세 정보 및 관련 코드 확인
- Gemini AI를 이용한 오류 원인 분석
- AI 기반 해결 순서, 주의사항, 관련 키워드 생성
- 기존 해결 기록에 AI 분석 추가
- 조회수 및 `도움이 됐어요` 기능
- 로그인/회원가입 없이 모든 사용자가 공개 기록 열람
- PC, 태블릿, 모바일을 지원하는 반응형 웹 UI

## Google API

**Google Gemini API**를 사용했습니다.

사용자가 입력한 오류 메시지, 사용 기술, 버전, 상황 설명, 관련 코드 등을 Gemini API에 전달하여 다음 내용을 분석합니다.

- 오류 내용 요약
- 발생 가능성이 높은 원인
- 확인 및 해결 순서
- 해결 과정에서 주의할 점
- 관련 기술 키워드

Gemini API는 Next.js 서버에서만 호출하며 API Key가 사용자 브라우저에 노출되지 않도록 구성했습니다.

## 데이터베이스

**Supabase PostgreSQL**을 사용했습니다.

Supabase에는 다음 데이터를 저장합니다.

- 오류 제목
- 오류 메시지
- 사용 기술 및 버전
- 오류 발생 상황 설명
- 관련 코드
- 실제 해결 방법
- 태그
- Gemini AI 분석 결과
- 조회수
- 도움됨 수
- 등록 및 수정 시간
- 익명 사용자의 과도한 요청을 제한하기 위한 요청 횟수 정보

로그인 기능은 사용하지 않으며, 데이터베이스 접근은 Next.js 서버에서 Supabase Secret Key를 이용해 처리합니다.

## 사용 기술

- **Next.js 16** - 웹 애플리케이션 및 서버 API
- **React 19** - 사용자 인터페이스
- **TypeScript** - 타입 기반 개발
- **Tailwind CSS 4** - 반응형 UI 디자인
- **Supabase PostgreSQL** - 오류 및 해결 기록 데이터베이스
- **Supabase JavaScript SDK** - Next.js와 Supabase 연결
- **Google Gemini API** - 개발 오류 AI 분석
- **Zod** - 사용자 입력값 검증
- **GitHub** - 소스 코드 관리
- **Vercel** - 웹서비스 배포
